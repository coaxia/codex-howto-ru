# Задание benchmark

Реализуйте браузерную игру в стиле 2048 без зависимостей по
[README.md](README.md), соблюдая исходный [AGENTS.md](../../../../labs/2048-game-benchmark/AGENTS.md).

Требования:

1. Сохраните предоставленные тесты побайтово.
2. Реализуйте движок и браузерные файлы минимальным целостным решением.
3. Выполните обязательные проверки и изучите финальный diff.
4. Не добавляйте зависимости, сгенерированные ресурсы или сетевые вызовы.
5. Запишите в `benchmark-final.md`:
   - изменённые файлы;
   - точные проверки и результаты;
   - реально выполненные действия в браузере;
   - всё непроверенное;
   - остаточные риски.

Для завершения нужен успешный `node --test`.
Не заявляйте браузерную проверку без фактического взаимодействия с браузером.
