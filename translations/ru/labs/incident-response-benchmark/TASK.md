# Задание benchmark

Реализуйте dashboard реагирования на инциденты без зависимостей по
[README.md](README.md), соблюдая исходный [AGENTS.md](../../../../labs/incident-response-benchmark/AGENTS.md).

Требования:

1. Сохраните предоставленные тесты побайтово.
2. Реализуйте хранилище, HTTP API и браузерный клиент минимальным целостным решением.
3. Выполните обязательные проверки и изучите финальный diff.
4. Не добавляйте зависимости, сгенерированные ресурсы, шаги сборки или сетевые вызовы.
5. Запишите в `benchmark-final.md`:
   - изменённые файлы;
   - точные проверки и результаты;
   - реально выполненные действия в браузере;
   - интеграционные переделки и конфликты ответственности;
   - всё непроверенное;
   - остаточные риски.

Для завершения должны пройти предоставленные тесты и оценщик после запуска.
Не заявляйте браузерную проверку без реального взаимодействия с браузером.
