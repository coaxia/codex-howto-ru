# Периодическая проверка расхождений документации

Используйте этот запрос только в периодической автоматизации Codex
с доступом к репозиторию на чтение:

```text
Изучи README.md, CATALOG.md, modules/ и актуальное официальное руководство Codex.

Цель:
Найти устаревшие, зависящие от версии утверждения о Codex или официальные ссылки.

Ограничения:
- Только чтение.
- Не меняй файлы, не открывай issues, не публикуй сообщения и не устанавливай зависимости.
- Считай официальную документацию OpenAI авторитетной.
- Сообщай только утверждения, которые можно подтвердить или опровергнуть.

Завершено, когда:
- каждое замечание ссылается на локальный файл и официальный источник;
- отсутствие изменений даёт краткий ответ «подтверждённых расхождений нет»;
- недоступные источники обозначены недоступными без догадок.
```

Выполните вручную до настройки расписания. Проверьте первый результат
по расписанию перед решением о добавлении действий записи.
