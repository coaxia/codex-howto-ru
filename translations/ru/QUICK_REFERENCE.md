# Краткий справочник

Примеры по конкретным проблемам — в [10 практических советах](resources/codex-tips.md).

## Условия задачи в запросе

```text
Цель:
Контекст:
Ограничения:
Завершено, когда:
```

## Где хранить инструкции

| Потребность | Механизм |
|---|---|
| Только текущая задача | Запрос |
| Устойчивое правило репозитория | `AGENTS.md` |
| Повторяемый процесс | Навык |
| Специализированная делегируемая роль | Пользовательский агент |
| Актуальные внешние данные или действие | MCP / коннектор приложения |
| Обобщённые подтверждения и развивающиеся знания | Живая wiki |
| Механическая проверка жизненного цикла | Hook |
| Распространяемый комплект | Плагин |
| Задача по расписанию или без постоянного участия человека | Автоматизация |

## До редактирования

- Для нового класса задач начните без навыка.
- Вызывайте `$engineering-loop`, только если полный цикл улучшает измеренный результат.
- Проверьте репозиторий и активную ветку.
- Изучите применимые `AGENTS.md`.
- Проверьте рабочее дерево на изменения пользователя.
- Найдите команды, определяющие завершение.
- Решите, нужен ли план.

При оценке навыка сравнивайте запуски без навыка, с прежней полной и текущей
компактной версиями при одинаковой модели и уровне рассуждений.

## До делегирования

- Явно вызовите `$orchestrate-engineering` для сложной задачи с независимыми потоками работы.
- Действительно ли задача независима?
- Ограничены ли вход и выход исполнителя?
- Может ли он остаться только на чтение?
- Будет ли сводка меньше его рабочего контекста?
- Могут ли одновременные правки конфликтовать?

## До приёмки

- Изучите diff.
- Сначала выполните целевые тесты.
- Выполните обязательные проверки репозитория.
- Проверьте ветви отказа и откат.
- Убедитесь, что секреты и сгенерированные артефакты не добавлены.
- Запросите оставшиеся предположения и непроверенные утверждения.

## Операции живой wiki

Названия операций и исходные примеры вызовов сохранены:

```text
$maintain-codex-wiki Query ...    # Read-only by default
$maintain-codex-wiki Capture ...  # Preserve a durable engineering lesson
$maintain-codex-wiki Ingest ...   # Register, compile, lint, review
$maintain-codex-wiki Archive ...  # Save cited synthesis as experimental
$maintain-codex-wiki Lint ...     # Mechanical checks plus semantic findings
$maintain-codex-wiki Promote ...  # Explicit move into a durable surface
```

Query читает; Capture фиксирует устойчивый урок; Ingest регистрирует источник,
обобщает и проверяет; Archive сохраняет экспериментальное обобщение со ссылками;
Lint проверяет форму и смысл; Promote явно переносит знания в устойчивый механизм.

```bash
python3 skills/maintain-codex-wiki/scripts/wiki_lint.py .
```

Храните внешние тексты в `.wiki-cache/`, а не в публичном репозитории,
если их распространение не разрешено.

## Полезные команды

```text
/init          Create a starter AGENTS.md
/plan          Enter planning mode
/review        Review a branch, commit, or working tree
/permissions   Inspect or change the current permission mode
/agent         Inspect agent threads in the CLI
```

`/init` создаёт начальный `AGENTS.md`; `/plan` включает планирование;
`/review` проверяет ветку, коммит или рабочее дерево; `/permissions` показывает
или меняет разрешения; `/agent` показывает потоки агентов CLI.
Доступность меняется: сверяйтесь с [официальной документацией CLI](https://developers.openai.com/codex/cli).
