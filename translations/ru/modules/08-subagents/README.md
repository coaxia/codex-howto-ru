# 08 · Субагенты

Необязательный эксперимент: [hooks маршрутизации моделей](../../examples/hooks/model-routing/README.md)
применяют настраиваемые уровни сложности к поддерживаемым нативным вызовам
создания агентов. Прочитайте ограничения совместимости и проверьте фактическую
модель дочернего агента перед использованием.

## Результат

Делегируйте узкие задачи изолированным потокам агентов, сохраняя контроль
над границами работы и подтверждениями.

## Что подходит для делегирования

- исследование кодовой базы;
- независимое изучение документации;
- анализ тестов или логов;
- отдельные проходы ревью безопасности, пробелов тестирования и сопровождаемости;
- независимые модули с исключительной ответственностью.

Что подходит плохо:

- два агента, редактирующие одни файлы;
- строго последовательная работа, где каждый шаг зависит от предыдущего;
- маленькая задача, для которой координация дороже выполнения;
- расплывчатое поручение «реализуй всю возможность».

## Контракт делегирования

Каждый исполнитель должен получить:

```text
Цель:
Границы задачи:
Разрешённые действия:
Требуемые подтверждения:
Формат результата:
Условие остановки:
```

Просите возвращать выжимку подтверждений, а не сырые логи.
Главный агент отвечает за интеграцию и финальную проверку.

## Пользовательские агенты

Агенты проекта находятся в `.codex/agents/*.toml`,
личные — в `~/.codex/agents/*.toml`.

Обязательные поля: `name`, `description`, `developer_instructions`.
`sandbox_mode`, `model` и уровень рассуждений — необязательные переопределения;
неуказанные значения наследуются через конфигурацию Codex.

В этом примере необязательно переопределён режим только чтения:

```toml
name = "reviewer"
description = "Read-only reviewer for correctness and regression risks."
sandbox_mode = "read-only"
developer_instructions = """
Lead with consequential findings.
Cite files and explain impact.
Do not modify code.
"""
```

Если модель не указана, агент наследует настройки по умолчанию.
Закрепляйте модель или уровень рассуждений только при наличии измеренной причины.

## Упражнение

Используйте [explorer](../../../../examples/agents/explorer.toml)
и [reviewer](../../../../examples/agents/reviewer.toml) из репозитория:

```text
Используй explorer для исследования затронутого пути выполнения, затем
reviewer для изучения текущего diff с учётом полученных подтверждений.
Оба агента должны работать только на чтение. Верни только подтверждённые
замечания со ссылками на файлы.
```

## Проверка

- У каждого исполнителя была одна ясная обязанность.
- Исполнители не редактировали пересекающиеся файлы.
- Сводки содержат подтверждения и неопределённость.
- Главный агент изучил объединённый результат.
- Делегирование улучшило качество или время настолько, чтобы оправдать расход токенов.
